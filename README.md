# Paradise Nursery - Aplicación de Carrito de Compras

**Paradise Nursery** es una aplicación web de comercio electrónico desarrollada con **React** y **Redux Toolkit** para una tienda de plantas de interior en línea.

## Características principales
- Página de inicio con presentación de la empresa y botón de **Comenzar**.
- Catálogo organizado en 3 categorías con 6 plantas de interior únicas por categoría (18 en total), cada una con imagen, nombre, descripción y precio.
- Gestión dinámica del carrito de compras con Redux Toolkit (agregar, eliminar, aumentar y disminuir cantidades).
- Cálculo automático del subtotal por planta y del importe total del carrito.
- Barra de navegación persistente con enlaces a **Inicio**, **Plantas** y **Carrito** con contador dinámico de artículos.
